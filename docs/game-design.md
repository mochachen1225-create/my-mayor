## 1. 一句話
> **市長不是神，是幕僚造出來的神。**

你是被派進戰情室的幕僚。老闆是抽到的，你沒得選；你只能在選前四個月裡，想辦法把他「養」到選得上。

- 平台：手機網頁（免安裝，連結可直接分享）
- 一局：約 10 分鐘
- 類型：選擇驅動 + 養成 + 多結局（結局圖鑑驅動重玩）
- 語氣：諷刺搞笑為主，結局偶爾催淚

## 2. 鐵律
1. **不出現任何真實人名、地名、政黨名、媒體名、節目名、企業名、宗教場所名。** 現實事件只取「類型」改編。
2. **不只酸某一邊。** 四位候選人槽點強度一致，每位都有讓他變好的「真結局」；各政黨都有黑歷史；名嘴、媒體兩邊都有。
3. 不寫成「某人確實犯了某罪」的指控；不使用已被查證為假的傳聞；不拿真實暴力事件開玩笑；不嘲笑外貌、家人私事。
4. 任何虛構名稱完成後要再檢查一次，避免諧音或字形直接對到真人。

- **性格**：隨機抽，玩家不能選

- **名字**：玩家自己取，預設英文名（A Andrew／Amy、B Ben／Bella、C Charles／Claire、D Dylan／Diana）。遊戲本身不給任何中文姓名，避免被影射

## 7. 回合結構
核心循環：**有火就滅火，沒火就造神。**

每週分成兩段：
1. **滅火**：有事件就跳出全螢幕緊急卡牌，必須馬上決定
2. **造神**：沒有火的時候；沒有話題，就要創造話題，從 3 張「造神企劃」卡裡挑 1 張主動出擊，例如拍親民短影音、跑菜市場、上節目、發政見、找網紅合作、辦造勢、拜託同黨議員帶去掃街拜票、拜託里長動員。不同老闆擅長的企劃不同，老闆也可能不配合

1. 每週 1–2 個事件，全局約 22–25 個
2. 每個事件給 2–4 個選項，**20 秒倒數**；突發事件縮短到 15 秒
3. 超時也算一個選項，通常最差（「○○陣營已讀不回」）
4. 選擇後先判定信任：老闆可能照做、改做、或做相反的事
5. 結果卡顯示數值變化，以及媒體或網友的反應

## 8. 事件系統
### 8.0 雙面事件（核心原則）
同一個事件會依老闆身分出現兩種版本：
- **現任（D）**：要**處理、滅火**
- **挑戰者（A／B／C）**：要決定**打不打、怎麼打**。打得太狠會反噬，例如被說「拿孩子做政治」「消費災難」

| 事件 | 現任版 | 挑戰者版 |
|---|---|---|
| 🍱 免費營養午餐 | 政策上路後廚餘暴增；局長在議會說「剩食可以給弱勢」，引發眾怒。要切割局長、道歉，還是反批對手製造恐慌？ | 某校傳出學生腹瀉，要不要大打食安？查證後如果只有少數個案，就會被反咬造謠 |
| 🛐 參拜禮儀 | 老闆在廟裡的動作被拍到，網友說沒禮貌。要道歉、說明，還是請廟方出來緩頰？ | 要不要轉發影片？宮廟系統的票可能被你一起得罪 |
| 🌀 颱風來襲 | 暫停競選、坐鎮防災中心，但曝光變少 | 照跑行程被罵冷血；也暫停的話，就沒有新聞 |
| 🎬 競選影片素材 | 影片被發現用了未授權畫面，又被質疑挪用市府宣傳片 | 要不要追打「公私不分」？ |
| 🐷 豬隊友 | 同黨議員自作主張發 AI 圖幫你攻擊對手，網友說是火上加油 | 同上，四位老闆都可能遇到 |
| 🕯️ 告別式拈香 | 在告別式上貼競選貼紙，被轟踩紅線 | 同上，四位老闆都可能遇到 |

### 8.1 主線（固定時間）
登記、抽號次、辯論、掃街、選前之夜、投票日。

### 8.2 突發事件（紅色警報）
- 颱風要不要放假
- 市府網站大當機，被酸「智慧城市」
- 幼兒園虐童案，市府被批處理太慢
- 河濱煙火人潮失控
- 天穹體育館又漏水
- 知名餐廳食物中毒

現任要決定**怎麼處理**；挑戰者要決定**要不要去蹭、怎麼打**。

### 8.3 選戰危機
- 十幾年前的舊文被挖出來
- 「證明我不是權貴」親民影片翻車
- 長輩今晚要上台助選
- 名人站台，引發另一波爭議
- 對手抄你的政見
- 深夜被突擊直播

### 8.4 戰情室日常（笑點來源）
- 實習小編用錯帳號發文
- 便當訂到對手的競選便當
- 迷因爆紅，但意思被曲解
- 網紅開價合作
- 志工群組吵架
- 印好的看板字印錯

### 8.5 金主來訪
| 選項 | 當下 | 後果 |
|---|---|---|
| 公開收、依法申報 | 資金小增 | 被說跟財團好 |
| 化整為零，讓員工分批捐 | 資金大增 | 🟡 選前有機率被記者查到 |
| 收下，答應「選上後幫個忙」 | 資金暴增 | 🔴 結局後必定引爆 |
| 婉拒 | 良心增加 | 金主轉去捐給對手 |

四位老闆的差異：A 長輩早就答應人家了；B 最缺錢，黨部暗示「別人都這樣」；C 不缺錢，但會順手答應人家；D 手上有職權，對價最直接。

帳是你經手的，所以可能出現「老闆沒事，你被起訴」。

### 8.6 議員、里長
- 拜託同黨議員、里長動員，要花人情帳和資金
- 母雞帶小雞（老闆民調高，大家搶著同框）vs 小雞怕被拖累（民調低時，議員開始切割）
- 對方回頭討人情：出席宮廟活動、喬補助、站台時排他前面

### 8.7 政論節目
- 每週一次「名嘴風向」
- 選項：親自上節目（高風險、高聲量）、派發言人、發新聞稿、已讀不回
- 名嘴會把你上週的決定斷章取義，兩邊的節目各罵各的

### 8.8 落後危機（對手民調大幅領先）
每次內參民調之後判定一次：落後 8% 以上就觸發。
- 對手陣營發布自家民調：「領先 15%！」數字是真是假，你要判斷
- 金主打電話來：「你們還有機會嗎？」不處理就撤資
- 同黨議員開始切割，看板上不再放老闆的照片
- 戰情室士氣低落：每週都有人請假，肝指數掉得更快
- 翻盤選項：打悲情牌、喊棄保、打負面選戰、換主打議題。每一招都有副作用，負面選戰會扣良心
- 反過來，**自己大幅領先**時也會觸發「輕敵」事件：老闆開始放鬆、亂講話
