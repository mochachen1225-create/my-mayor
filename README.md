# 我推的市長

> 市長不是神，是幕僚造出來的神。

你是爆肝的**競選總幹事**。老闆（市長候選人）是抽到的，你沒得選。
選前四個月，在戰情室裡滅火、包裝、拉票，想辦法把老闆送上市長寶座。

👉 **線上玩：https://mochachen1225-create.github.io/my-mayor/**
手機打開就能玩，免安裝、免登入，一局約 10 分鐘。

![我推的市長](og.png)

## 遊戲特色
- **六位老闆隨機抽**：政治世家第三代、清新專業人士、商業帝國老闆、現任市長、黨內資深黨員、草根律師。性格是抽到的，性別和名字由你決定。
- **老闆不一定聽你的**：信任不夠，他會照自己的個性亂來。
- **20 秒做決定**：突發事件一件接一件，時間到沒選就是擺爛。讀太慢？首頁選「🐢 我想慢慢來」就不倒數。
- **41 種選舉結局＋14 種總幹事結局**：老闆選上、落選、驗票翻盤……而你自己，可能是最忠心的總幹事，也可能是「被告的是你」。
- **總幹事也有私心**：可以幫老闆，也可以偷偷幫自己。被老闆發現的話……
- **每月政見發表**：要開支票討好選民，還是說逆耳的真話？
- **結局圖鑑**：每個結局都有一張附吐槽的小卡，標上稀有度；還能回頭看每一局的檢討會。
- **每局都不一樣**：事件、空檔、結果都是隨機的，上一局遇過的事件比較不會再出現。

## 怎麼玩
1. **有火就滅火**：突發事件跳出來，在倒數內選一個回應。
2. **沒火就成就老闆**：從戰情室行程板挑一件事，像掃街、上節目、辦造勢、形象包裝。
3. **看數值**
   - 候選人：聲量、民調好感度、競選資金、對你的信任
   - 總幹事（你）：肝的健康、團隊士氣、你的信心
   - 主要對手的聲勢
4. **每月一次內參民調**，最後 10 天民調封關。
5. **11/28 開票**，接著是選戰檢討會和結局。

### 小訣竅
- **民調好感度高的時候，聲量越大，民調漲得越快**；好感度低的時候，越紅越扣分。
- 多選老闆擅長的事，他比較會聽你的。
- 每位老闆都有「形象任務」，但包裝太密集會被說作秀。
- 每位老闆在意的不一樣：有人要乾淨，有人只要贏。
- 民調領先太多，支持者可能不出門投票，記得催票。
- 壞事做多了……你懂的。

遊戲裡右上角的 ☰ 選單有完整的「總幹事手冊」。玩到一半關掉也沒關係，下次打開可以「繼續上一局」。

## 聲明
本遊戲**純屬虛構**。城市、政黨、人物皆為虛構，不指涉任何真實人物、政黨或地區。
事件只取現實中常見的「類型」改編，不代表任何事實指控，也不支持或反對任何政黨。
