# 2. 實作

## 架構
純 HTML／CSS／JS，沒有框架，部署在 GitHub Pages（push 就更新）。

```
index.html          入口、Open Graph、每個檔案加 ?v=版本號
style.css
js/i18n.js          語言判斷、T()、資料整批翻譯
js/i18n.en.js       英文對照表 { 中文原文: English }
js/avatar.js        SVG 頭像產生器；有插畫就用插畫
js/data.js          所有內容：角色、事件、行程、結局、網友留言（只有資料，沒有邏輯）
js/fx.js            音效、震動、彩帶、飄字（只管手感）
js/engine.js        遊戲邏輯，不碰畫面，可以在 Node 裡跑模擬
js/game.js          畫面與流程
art/                插畫（webp，256×256）
scripts/            打包腳本
promo/              宣傳素材
docs/               企劃、上架資料
```

重點：**engine 完全不碰 DOM**，所以可以用 Node 的 `vm` 載入 data.js＋engine.js 跑上千局模擬。隨機數用 `g.rng`（可以給種子），UI 專屬的隨機（網友留言、開票動畫）才用 `Math.random`，不影響模擬。

## 一定要有的系統
- **存檔**：每週開始時存 localStorage（不存亂數產生器，讀檔後重新接上）。所有 localStorage 讀寫都包 try/catch（無痕模式會丟錯）。
- **版本與快取**：`VERSION`、首頁「🆕 遊戲更新了」小連結（點了才展開 `CHANGES`），`index.html` 每個檔案加 `?v=`。
- **結局圖鑑**：分類分頁（換行排列，不要左右滑）、稀有度（依模擬出現率）、結局小卡（一句吐槽、怎麼拿到、第一次解鎖的日期、拿過幾次、完整故事），未解鎖的不要給提示。
- **選戰紀錄**：最近 30 局，可以回看檢討會（幫最多和傷最重的決定、總評、數據）。
- **分享截圖**：canvas 1080×1350；emoji 和文字分開畫（手機上量 emoji 寬度不準，一起置中會歪）；英文要按單字斷行；字太長就自動縮小。
- **分享文字**：固定格式加遊戲網址。
- **節奏選擇**：首頁可選「慢慢來（不倒數）」或「極限模式」，選單裡也能切換。倒數制的遊戲一定要有，不然讀得慢的人會覺得被時間追著跑。
- **選單**：繼續、切換節奏、音效開關、手冊、結局圖鑑、回首頁；打開時倒數暫停。

## 讓遊戲「好玩」的手感（v2.0 加的，效果很大）
- **網友留言**：每個結果下面 2～3 則社群留言，依結果分類（好評、出包、角色不聽話、已讀不回、髒招、連擊、倒下），偶爾出現角色家人留言。純氣氛，用 Math.random。
- **連擊**：連續處理得好有獎勵（只加士氣、信心，不直接加核心分數，避免滾雪球）。
- **小遊戲**：例如 10 秒點冒出來的人握手。畫面算分，engine 只收三級（差／普通／超好，效果 ×0.4／×1／×1.8），模擬時當作普通。一定要有「跳過（普通結果）」按鈕。
- **開票／結算動畫**：即時數字、主播播報、差距小時先落後再逆轉、心跳聲越來越快、可跳過。
- **音效**：用 WebAudio 現場合成，不用音檔；首頁和選單可以關。
- **震動**：`navigator.vibrate`（只有部分 Android 支援）。
- **HUD 飄字**：數值變動時飄出 +3／−2，格子短暫變色。用動畫做變色，不要留下會殘留的 class 樣式。
- **最後 5 秒**：倒數條變紅、滴答聲。

## 狀態歸零要有後果
任何會歸零的資源（例如肝、體力）都要在**每一步之後**檢查，不能只在某個畫面檢查。我們的 bug：行程板會強制休息，但突發事件卡不檢查，結果肝 0 還能一直玩。修法：任何一步之後歸零就當場倒下，這週剩下的事全部跳過，給明確的懲罰和專屬留言。
