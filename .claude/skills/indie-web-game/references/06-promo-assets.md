# 6. 宣傳素材

## 試玩廣告影片（直式 9:16，約 25～30 秒，中英兩版）
風格：迷因貼紙字卡＋熱血配樂，用很澎湃的音樂配很荒謬的劇情。字卡兩行：白字黑邊＋黃底或紅底的貼紙，稍微歪一點。

### 1) 照劇本演一局、拍素材（`scripts/stage_scenes.js`）
- **不要用 Playwright 的錄影**，那只有 CSS 解析度，會很糊。CSS `zoom` 也不行，會破壞 vh 版面。
- 用 viewport 400×800、deviceScaleFactor 2.4（＝960×1920）：
  - 靜態畫面：直接截圖。
  - 會動的畫面（翻牌、小遊戲、開票）：連拍 jpeg 截圖並記錄時間戳，大約 13～15 fps，夠用。
- 直接呼叫 game.js 的全域函式來導戲：`roomScreen()`、`eventCard(EVENTS.find(...))`、`sweepGame()`、`forcedRest()`、`electionNight()`。改 `G.rng` 控制結果（例如讓老闆不聽話），改 `G.s`／`G.r` 安排逆轉。
- 用 `Math.random` 暫時覆寫來指定抽到的角色。
- 中文、英文各跑一次（`addInitScript` 設語言）。

### 2) 字卡（`scripts/caption_cards.html`）
用 Playwright 把每張字卡截成透明 PNG；片尾卡（角色頭像、遊戲名、「Play free in your browser」）截成 1080×1920。

### 3) 剪輯（`scripts/build_trailer.py`）
- 每段：遊戲畫面縮到 960×1920，放在 1080×1920 的模糊背景上；靜態圖加輕微推近（zoompan）；連拍用 concat 依時間戳排，可以快轉。
- 字卡從上方滑入；畫面上方有角色臉的時候，字卡改放下方。
- 每段開頭加 0.05 秒白閃。
- 音樂對拍：把「勝利」那一刻對到音樂轉強的地方；片尾卡出現時對到曲子最後一個重音，再用曲子本身的結尾淡出，不要硬切。
- 用 ffmpeg 分析音樂：每 20ms 算 RMS 找起音點和段落變化。
- 先抽幾格拼成縮圖檢查：字卡有沒有蓋到臉、時間有沒有對。

### 用 Flow 的 AI 影片剪功能宣傳短片（`scripts/build_promo_with_ai_clips.py`）
- 總編會把作者生的影片推到 `art-inbox` 分支，用 `git show origin/art-inbox:路徑 > 檔案` 取出。
- 先抽格拼成縮圖，看每支在演什麼、哪幾秒最好用；角色不是同一個人也沒關係，但不能像真人。
- AI 影片段落一律在左下角加「🤖 AI 生成畫面／AI-generated footage」。
- AI 常在電視、招牌上生出亂碼字：用字卡蓋住，或者把那一塊裁下來模糊再疊回去（範圍不要太大，不要切到人）。
- 結構：AI 影片開場（情境）→ 真實遊戲畫面 3～4 段（功能本身）→ AI 影片收尾（情緒）→ 片尾卡（加一行「新版・功能名稱」或「真實日期」）。

### 也可以用作者給的影片
作者用 Gemini 生的影片片段（要拿掉 Gemini 原本的配音），用 ffmpeg 加集中線、衝擊幀、推近、色調、字卡。角色看起來可怕的話就換掉片段。也可以做 5～10 秒的短版，只放「還在努力」的部分，結局留給玩家。

## 截圖（itch 用 6 張，4:5，1080×1350）
彩色漸層背景＋上方歪歪的大標題＋黃色小標籤＋中間手機框裡放遊戲畫面。挑最有梗的畫面：角色是抽的、角色不聽話、網友留言、小遊戲、逆轉、結局。中文版可以直接當 IG 輪播。

## 封面與圖示
- itch 封面：630×500，實際做成兩倍大（1260×1000）。
- Newgrounds 圖示是**橫的**（大約 16:9，縮圖又會裁成約 1.55:1）：重要的東西放中間，角色在左、標題在右，做 1920×1080。
- 正方形圖示：512／1024。
- 遊戲名稱用很有個性的字體（Luckiest Guy），中文用 Noto Sans TC 900。

## 檔案放哪
`promo/`（影片）、`promo/itch/`、`promo/newgrounds/`，都推上 repo。作者在 App 裡下載不了檔案時，可以給 GitHub raw 連結。
