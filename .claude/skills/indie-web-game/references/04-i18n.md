# 4. 中英雙語

## 架構：中文原文當 key
- `js/i18n.js`：
  - `LANG`：玩家選過就照選的；在 itch.io（網域 itch.io／itch.zone／hwcdn.net）上一律英文；其他地方看瀏覽器語言（中文介面 → 中文，其他 → 英文）。
  - `T(s, ...args)`：英文模式查表，代入 `{0}`、`{1}`；`{M0}` 代表「第 0 個參數是月份，顯示成 Aug」。
  - `translateDeep(obj)`：把資料物件裡的字串整批換成英文。
- `js/i18n.en.js`：`I18N.en = { "中文原文": "English", ... }`。
- `data.js` 不用改：在 `game.js` 開頭，英文模式時對所有資料常數跑 `translateDeep`。
- `engine.js`、`game.js` 的中文字串用 `T()` 包起來。
- `data.js` 最上面放備用的 `T`（模擬時沒載入 i18n.js）：
  `if (typeof T === 'undefined') { var T = (s, ...a) => s.replace(/\{M?(\d+)\}/g, (m, i) => (a[+i] !== undefined ? a[+i] : m)); }`
- 載入順序：i18n.js → i18n.en.js → avatar.js → data.js → fx.js → engine.js → game.js。
- 首頁放語言切換（中文／English），切換就存 localStorage 再重新整理。英文版首頁加一個「New to …? Read this first」的文化小知識。
- `fill()` 支援 `{he}`／`{He}`／`{him}`／`{his}`，英文需要受格和所有格。

## 自動包字串（不要手改幾百行）
`scripts/wrap_i18n.js`（用 acorn 解析）：
- 把含中文的字串和樣板字串改成 `T('…')`。
- 樣板字串會在 HTML 標籤處切開，只包文字節點；插值變成 `{0}` 參數。
- 物件的 key、已經是 `T()` 的不動。
- 用法：`npm i acorn acorn-walk`，然後 `node wrap_i18n.js js/game.js`。

包完之後一定要檢查：
1. **區域變數叫 `T` 的地方**（例如 `const T = TYPES[type]`）會蓋掉翻譯函式，執行時出現「T is not a function」。只改「名稱是 T」的識別字，宣告本身（VariablePattern）要另外改。**千萬不要寫成把函式裡所有識別字都改名**，我們就是這樣把四個函式改壞，最後只好從 git 拿回原版重做。
2. **中文被拿來做邏輯判斷的地方**：`.replace(T(…))`、`.includes(T(…))`、`=== T(…)`。翻譯後就對不上了，要改成不依賴文字的寫法。
3. **HTML 屬性裡的中文**（aria-label、alt）不會被包，要手動改成 `${T('…')}`。
4. **碎片句子**：程式在中文後面直接接 `'」。'` 或 `'？'.repeat(n)`，要把整句改成一個 `T('…{0}…')`。

## 抽字串＋平行翻譯
- `scripts/extract_i18n.js`：走訪 data.js 的資料常數，加上 engine/game 裡 `T('…')` 的第一個參數，輸出 `[{zh, ctx}]`，ctx 是來源位置或那一行程式。
- 我們約 2,700 句、4 萬字，分成 6 份，用 6 個 agent 同時翻譯，大約 3 分鐘。
- 先寫一份翻譯指引＋詞彙表，所有 agent 共用（範例：`references/translation-brief-example.md`）。內容包括：語氣、placeholder 規則、月份 `{M0}`、代名詞、禁止真實名稱、隱藏規則不能寫出來、固定譯名。
- 每個 agent 要自己用 Python 檢查：JSON 能解析、key 齊全、placeholder 都在。
- 合併後再檢查一次：缺漏、placeholder、英文裡有沒有殘留中文。
- 翻譯 agent 會把原文裡的真實平台名（Facebook、IG、某論壇）、真實歌名換成泛稱，看它們的回報，必要時連中文原文也一起改。

## 版面
- 英文通常比中文長：標題要能換行（不要在連字號處斷），按鈕和數值格要看一遍。
- 分享截圖的斷行要按單字。
- 加新字串時，同一個 commit 就把英文補進 `i18n.en.js`，寫進新遊戲的 CLAUDE.md。
